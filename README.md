# BlackVault Immersive Website — Historical Design Reference

**Documentation status:** Historical reference · Updated 2026-09-18

This repository preserves earlier BlackVault website layouts, visual assets, and interactive concepts. The active product documentation is maintained in [BlackVault Public Network](https://github.com/blackvault-opps/Blackvault-Public-Network-repo).

## Current ecosystem

SafeVault is designed around a primary BlackVault smart account, with optional external-wallet connections. Vault Coin is the Ethereum-mainnet production-token project; FUNTOKEN has a separate Sepolia testnet history. Vault AI is the workspace assistant and evidence-based discovery agent.

The older Nexus/game routes in this repository belong to a retired prototype and are not active wallet, rewards, or asset-recovery functionality. Non-gaming visual assets can be evaluated individually for reuse with source provenance preserved.

## Repository contents

- Existing HTML entry points and `src/` front-end source.
- Historical interactive routes under `nexus/`.
- Visual assets under `public/assets/`.
- An earlier standalone package under `blackvault-immersive-website (3)/`.
- Vite package configuration and a Jekyll build workflow.

These contents establish a design/source archive, not a current SafeVault or Vault AI release. This update changes documentation only.
