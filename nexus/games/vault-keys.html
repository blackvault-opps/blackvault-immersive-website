    How to Play

    Vault Keys™ is a discovery game. Each round presents a 3×3 grid of concealed nodes.

    You get 3 scans per round. Click any concealed node to reveal what's hidden inside.

    Possible discoveries:

    🔑 Vault Key (Rare) — +50 XP
    🌀 Realm Fragment (Uncommon) — +35 XP
    📶 Signal Fragment (Common) — +20 XP
    ⚡ Nexus XP Bonus (Common) — +30 XP
    ○ Empty Signal (Common) — +5 XP
    👑 Rare Artifact (Legendary) — +100 XP

    Complete the mission by discovering 5 Vault Keys across multiple rounds for a massive XP bonus!
